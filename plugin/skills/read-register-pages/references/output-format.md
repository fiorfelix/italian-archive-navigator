# Output format for each act found

Use this layout (invented example):

```
Act 45 · Births · Montefiore · 1880                         page: montefiore_1880_nati_img046
Source: https://… (link to the page in its source)           evidence: VERIFIED

Surname as written:  ROSSI                 (high)
Given names:         Giuseppe Antonio      (high)
Event date:          5 March 1880          (high)
Place / house:       Via del Borgo [?]     (medium)
Father:              Luigi, contadino      (high)
Mother:              Maria Bianchi         (high)
Informant:           the father            (high)
Witnesses:           [illeggibile]; Pietro Verdi (low)
Margin:              annotation of marriage, 1905, act 12 [?] (medium)

Key passage: "… è comparso Rossi Luigi … contadino … il quale mi ha dichiarato che alle ore
dieci … è nato un bambino di sesso maschile … al quale dà i nomi di Giuseppe Antonio …"

Citation: Archivio di Stato di …, Stato civile italiano, Nati, Montefiore, 1880, atto di nascita
n. 45, https://… (consultato il …).
```

Rules:

- Keep names exactly as written; add the normalised form in brackets only if it differs.
- Dates: as written, then as yyyy-mm-dd when certain.
- Mark doubtful words `[?]`, unreadable parts `[illeggibile]`; confidence per field.
- One block per act. After the blocks, list near-matches (similar surnames) separately, as
  uncertain.
